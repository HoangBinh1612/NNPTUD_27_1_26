# Bài tập: Student Objects - JavaScript

**Họ tên:** Hoàng Dương Bình  
**MSSV:** 2280600262

## Mô tả

Bài tập tạo 3 đối tượng student bằng JavaScript với các thuộc tính (name, family, age, scores, birth) và các phương thức (getFullName, getFullBirthDay, getAVGScore, getAge).

## Cấu trúc project

- `student.js` — File JavaScript chứa 3 đối tượng student và test output
- `student.json` — File JSON tương ứng với dữ liệu 3 students
- `README.md` — File mô tả project
